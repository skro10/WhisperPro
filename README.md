# WhisperPro

WhisperPro is a Windows desktop app for fast, local voice dictation.

## Main features

- local voice dictation (button + global shortcut)
- fast Whisper transcription
- in-app model management (download, select, delete)
- transcription history
- optional translation
- dynamic mini-widget
- French/English interface

## Quick dev run

```powershell
cd apps/desktop
npm install
npm run tauri:dev
```
