# WhisperPro

**Fast local voice dictation for Windows.**

WhisperPro helps you speak naturally and get clean text in seconds, with a workflow designed for non-technical users.

[Download latest installer](https://github.com/skro10/WhisperPro/releases/latest) | [Support the project](https://buymeacoffee.com/skroproduction)

## What WhisperPro does

- records your voice and transcribes it quickly
- lets you launch dictation from a button or a global keyboard shortcut
- injects text directly into your current workflow
- keeps a clear transcription history you can copy or clean

## What is available right now (v1.0.0)

- local Whisper transcription on Windows
- model management in-app (download, select, remove)
- optional translation to a target language
- dynamic mini-widget with opacity and sound controls
- French and English interface
- installer-based distribution via GitHub Releases

## Why users choose WhisperPro

- **Simple UX**: clean interface, no technical overload
- **Daily productivity**: ideal for notes, messages, drafting
- **Local-first**: processing on your machine
- **Practical controls**: models, history, translation in one place

## Typical use cases

- writing emails and messages faster
- meeting notes and quick capture
- creating first drafts by voice
- multilingual dictation with translation

## Download and install

1. Open the latest release:
   [https://github.com/skro10/WhisperPro/releases/latest](https://github.com/skro10/WhisperPro/releases/latest)
2. Download `WhisperPro_1.0.0_x64-setup.exe`
3. Run the installer and launch WhisperPro
