# WhisperPro

**Speak. WhisperPro writes.**

WhisperPro is a Windows voice dictation app built for speed, clarity, and daily productivity.

[Download the latest release](https://github.com/skro10/WhisperPro/releases/latest) | [Support the project](https://buymeacoffee.com/skroproduction)

## Why WhisperPro

- fast dictation with clean text output
- direct text insertion in your active app
- compact live widget for dictation status
- clear history for copy and review
- French and English interface

## Version 1.5.0

- stronger overall stability
- improved options and widget behavior
- better punctuation and text formatting consistency
- polished light and dark themes

## Typical use cases

- writing emails and messages faster
- taking meeting notes in real time
- creating first drafts by voice
- dictating and translating text in seconds

## Installation

1. Open the latest release:  
   [https://github.com/skro10/WhisperPro/releases/latest](https://github.com/skro10/WhisperPro/releases/latest)
2. Download `WhisperPro_1.5.0_x64-setup.exe`
3. Run the installer
